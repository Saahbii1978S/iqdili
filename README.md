## تطبيق Android

نسخة Android ما زالت في مرحلة الاختبار. ملفات APK التي تُبنى عبر GitHub Actions هي ملفات تجريبية، وليست إصداراً رسمياً موجهاً للعموم أو منشوراً على Google Play.

## التطوير والنشر

- الموقع منشور عبر GitHub Pages.
- نشر الموقع يتم آلياً عند تحديث الفرع `main`.
- بناء APK التجريبي متاح عبر GitHub Actions.
- بناء حزمة Google Play ‏(AAB) يدوي ويتطلب مفاتيح توقيع محفوظة في GitHub Actions Secrets.
- لا تُدرج مفاتيح التوقيع أو كلمات المرور أو مفاتيح الخدمات السرية في ملفات المستودع.
